MelkkiPDF

A fast, minimal PDF viewer for Linux, inspired by SumatraPDF. Built with Slint and MuPDF.

Install

flatpak install @BASE_URL@/melkkipdf.flatpakref

Requires flatpak. This adds the MelkkiPDF repository and installs the viewer; flatpak update picks up new versions. The repository is signed and the public key travels with the ref, so flatpak verifies each build.

Launch it from your application menu, or with flatpak run @APP_ID@ document.pdf.

Features

  • Continuous and single-page reading modes
  • Single, odd, and even page spreads
  • Zoom, fit-width, and fit-page
  • Bookmark sidebar with page thumbnails
  • Keyboard-driven navigation
